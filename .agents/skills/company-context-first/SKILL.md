# Company Context First

1. Read `AGENTS.md`.
2. Read `docs/START-HERE.md`.
3. Read only the relevant canonical documents.
4. Check `knowledge/DECISION-STATUS.md` and `knowledge/OPEN-QUESTIONS.md`.
5. Classify every material statement as confirmed direction, working hypothesis, open decision, external validation required, or historical.
6. Do not choose the company name, ownership, legal structure, pricing, partner, distributor, or product unless the user explicitly approves it.
7. Cite repository paths when summarizing or proposing changes.
8. Identify contradictions before creating new material.
9. Update canonical documents and indexes when a decision is approved.
10. Run `python scripts/verify_repository.py` before completion.
