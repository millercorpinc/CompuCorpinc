# Decision Governance

1. Determine whether the matter is material.
2. Search existing decision records.
3. State context, constraints, and options.
4. Include benefits, costs, risks, reversibility, and evidence.
5. Identify qualified professional input required.
6. Do not mark a decision approved without explicit approval.
7. Create or update an ADR using `docs/decisions/ADR-0000-TEMPLATE.md`.
8. Update canonical documents.
9. Link implementation tasks.
10. If superseding a decision, preserve the old record and link both directions.
