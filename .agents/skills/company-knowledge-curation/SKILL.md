# Knowledge Curation

1. Identify source, date, and authority.
2. Separate facts, opinions, hypotheses, decisions, and historical context.
3. Find the canonical home for each item.
4. Reconcile contradictions; do not silently overwrite.
5. Create a proposed decision when new information changes direction.
6. Keep confidential customer details outside reusable solution patterns.
7. Add links rather than long duplicates.
8. Update indexes, decision status, open questions, and working log.
9. Record lessons from completed work using `templates/PROJECT-CLOSEOUT.md`.
10. Run repository validation.
