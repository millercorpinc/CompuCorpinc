# CompuCorp Brand Kit v1

## Purpose

This is a working brand kit for the company’s first pass at visual identity. It is intentionally focused on a technical, precise, industrial look that uses a warm orange as the primary identity signal while maintaining a clean, professional, and non-spooky visual tone.

This document is a starter system for internal use, design iteration, and future refinement. It does not replace a formal brand design engagement.

## Brand core

### Positioning

The company should feel:

- precise
- technical
- reliable
- practical
- mature
- engineered
- not theatrical
- not dark or ominous

### Brand personality

- Operationally competent
- Detail-oriented
- Security-conscious
- Credible and grounded
- Serious without being cold
- Technology-led but business-oriented

## Color palette

### Primary palette

- Main orange: #E97B1F
- Bright orange accent: #F39A42
- Deep charcoal: #1F2A2D
- Graphite: #4A545B
- Warm gray: #EAE3DC
- Off-white: #F7F4F1
- White: #FFFFFF

### Usage guidance

- Use orange as the signal color for identity, emphasis, and highlights.
- Use deep charcoal for headlines, key text, and structure.
- Use white or off-white for background space.
- Use gray for supporting text and secondary elements.
- Avoid large dark-black backgrounds unless the design specifically calls for contrast-heavy material.

## Typography direction

### Recommended styles

- Geometric sans-serif for headings and wordmark
- Clean sans-serif for body text
- High readability and strong structure
- Uppercase treatment for key brand moments

### Suggested type families

- Inter
- Montserrat
- Sora
- Manrope
- Exo 2
- Rajdhani

### Wordmark guidance

- Use uppercase for the company name in principal branding moments
- Maintain a strong, compact, industrial-looking wordmark
- Keep the character spacing slightly tighter than standard sans-serif to add precision
- Use the orange accent sparingly in the wordmark or on a single character or letterform if desired

## Brand direction themes

### 1. Technical precision

Use geometry, balance, and structure. The mark should feel engineered, clear, and deliberate.

### 2. Mechanical confidence

The company should not feel overtly soft or trendy. Industrial references should feel serious and useful.

### 3. Human trust with technical depth

The tone should be credible and grounded, not sinister or overly dramatic. The orange should signal warmth and capability rather than danger.

### 4. Operational excellence

The brand should signal that the company helps customers run well-governed systems, improve security, and create predictable operations.

## Recommended logo directions

### Direction A — Precision / measurement

This direction fits the company’s advisory and systems engineering identity.

Visual cues:

- compass or measurement symbols
- geometric locks
- technical precision
- architecture and governance

Best use:

- strategic / advisory / architecture documents
- founder-facing materials
- board decks and planning docs
- corporate website hero concepts

### Direction B — Grid / system / structure

This direction fits the company’s operational architecture and reliable systems emphasis.

Visual cues:

- geometric grid
- block structure
- network / matrix / system feel
- enterprise control and methodical execution

Best use:

- internal documentation
- dashboards
- operational docs
- project management and service materials

### Direction C — Hardware / signal / technical glow

This direction is more industrial and has a vintage technology feel.

Visual cues:

- vacuum tube / component / signal pattern
- warm glow
- retro-tech but modernized
- technical confidence and energy

Best use:

- brand hero art
- social or website brand art
- product / service launch materials
- presentation covers and campaigns

### Direction D — hybrid industrial mark

A hybrid of the above approaches, using a strong geometric icon plus a subtle warm-orange signal element.

Best use:

- default company mark
- general-purpose brand application
- primary website and document header treatment

## Recommended initial brand system

Use the following as the primary default system for version one:

- Primary wordmark: CompuCorp in uppercase, charcoal, geometric sans serif
- Primary accent: orange used for one feature or icon element
- Backgrounds: white and warm gray
- Secondary system: deep charcoal on white
- Optional reverse system: white on charcoal
- Icon style: clean geometric industrial mark with a subtle technical signal

## Working logo asset

`site/assets/compucorp-mark.svg` is the current internal working mark. It is an original, simplified vacuum-tube icon inspired by the provided orange-and-charcoal reference direction.

- Status: working internal asset, not a final legal or public mark
- Purpose: internal portal, founder materials, and early presentation layouts
- Design: one charcoal housing, one off-white tube silhouette, and a restrained orange signal core
- Constraint: preserve a simple geometric construction suitable for vector refinement, small sizes, and monochrome adaptation
- Source: founder-provided visual reference, August 18, 2026

Do not represent this mark as final or use it externally until the company name and trademark review are complete.

### Slide rule

- Keep diagrams clean and high contrast
- Use orange for a single core signal or feature
- Avoid too many orange elements in the same frame
- Let whitespace do the heavy lifting

### Social / hero art rule

- Use orange as the standout color but not more than 15–20% of the visual field
- Let the geometry and icon structure do the majority of the visual weight

## First-pass brand recommendation

The strongest first pass is a hybrid industrial / precision mark that feels:

- technical
- stable
- credible
- precise
- bright enough to stand out without feeling loud

If the final company identity is still not settled, keep the system flexible and design around the orange + charcoal + warm gray system rather than locking into a single final logo treatment too early.
