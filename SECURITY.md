# Security Policy

## Scope

This repository contains confidential business architecture, operating procedures, and potentially commercially sensitive plans.

## Do not commit

- Passwords, API keys, access tokens, certificates, or private keys
- Customer or prospect data
- Production configuration exports containing identifiers or secrets
- Regulated personal, financial, or health information
- Executed contracts containing private information unless an approved secure document process is established
- Vendor credentials or distributor account details

## Reporting

Report suspected exposure immediately to the designated security owner. Until roles are formally approved, the technology/security founder function owns triage.

## Design principles

- Least privilege
- Separation of customer environments
- Auditable administrative actions
- Secure defaults
- Reproducible configuration
- Documented exceptions
- Explicit data classification and retention
- Independent review for high-risk changes
