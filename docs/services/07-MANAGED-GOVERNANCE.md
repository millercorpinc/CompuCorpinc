# Managed Governance

## Status

Core recurring service.

## Purpose

Provide continuing ownership of the customer’s technology standards, security posture, documentation, vendor coordination, and roadmap after foundation work is complete.

## Standard domains

- Identity and privileged access
- Devices and endpoint security
- Collaboration and sharing
- User lifecycle
- Security posture
- Licensing
- Platform changes
- Documentation
- Vendor coordination
- Automation health
- Risk and exceptions
- Roadmap

## Possible cadence

### Monthly

- Change and incident summary
- Security posture
- Administrative changes
- License and vendor issues
- Open risks
- Roadmap progress

### Quarterly

- Executive service review
- Technology roadmap
- Security and risk review
- Cost and licensing review
- Improvement priorities

## Boundaries

Managed governance is not automatically unlimited help-desk support, 24x7 incident response, hardware break/fix, custom development, or every project request.

## Customer prerequisites

- Approved foundation or baseline assessment
- Named sponsor
- Agreed security standards
- Approved access model
- Clear support boundary
- Current documentation or funded remediation

## Commercial hypotheses

- Approximately $500–$2,000+ monthly for smaller governance engagements
- Approximately $5–$15 per user for lighter governance
- Higher pricing when the company assumes broader operational or support responsibility

## Success measures

- Reduced unmanaged risk
- Current documentation
- Timely access removal
- Stable security posture
- Roadmap progress
- Fewer preventable incidents
- Better vendor and license decisions
- Customer confidence and retention
