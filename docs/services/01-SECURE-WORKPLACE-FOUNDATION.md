# Secure Workplace Foundation

## Status

Presumptive launch service; requires final scope and commercial approval.

## Ideal customer

A 10–150-person organization using Microsoft 365 that lacks a consistent identity, endpoint, collaboration, security, and administrative baseline.

## Trigger events

- New Microsoft 365 tenant
- Acquisition or organizational separation
- Replacement of an incumbent provider
- Cyber-insurance or customer-security requirements
- Rapid growth
- Device-management rollout
- Security incident or near miss
- Executive concern about uncontrolled access or sharing

## Outcomes

- Governed identities and administrator access
- MFA and Conditional Access baseline
- Managed endpoints
- Endpoint security
- Controlled collaboration and sharing
- Clear ownership and documentation
- Prioritized remaining risks
- Readiness for recurring governance

## Standard scope

- Discovery and prerequisites
- Tenant and licensing review
- Identity and administrator baseline
- MFA and Conditional Access
- Privileged-access standards
- Device enrollment and management baseline
- Endpoint protection baseline
- Teams, SharePoint, OneDrive, and sharing foundations
- Security posture review
- User lifecycle procedure
- Documentation and administrative handoff

## Common exclusions

Unless explicitly included:

- Complex tenant-to-tenant migration
- Large data migration
- Custom application remediation
- Advanced compliance implementation
- 24x7 support
- Network redesign
- Hardware replacement
- Formal audit or attestation
- Extensive end-user remediation
- Unsupported operating systems or applications

## Prerequisites

- Authorized executive sponsor
- Administrative access
- Accurate user and device inventory
- Licensing authority
- Customer availability for decisions
- Agreement on legacy-risk treatment
- Backup or recovery plan for material changes

## Delivery stages

1. Discovery and inventory
2. Baseline assessment
3. Target configuration and exceptions
4. Pilot
5. Production rollout
6. Verification
7. Documentation and handoff
8. Recurring-governance proposal

## Acceptance evidence

- Approved configuration baseline
- Named administrative ownership
- MFA and access-policy evidence
- Managed-device inventory
- Endpoint-security status
- Sharing and collaboration settings
- User lifecycle runbook
- Open-risk register
- Customer acceptance

## Commercial hypothesis

Historical working range: approximately $3,500–$7,500 for a controlled environment, with higher pricing for takeover complexity, migration, cleanup, regulated requirements, nonstandard devices, or incomplete customer records.

## Recurring attach

- Managed governance
- Security review
- User and device administration
- License management
- Roadmap and quarterly review
- Selective help-desk or escalation support
