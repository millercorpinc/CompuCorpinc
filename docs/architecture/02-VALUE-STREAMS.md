# Value Streams

## 1. Market insight to qualified opportunity

Research → Target account → Outreach → Discovery → Qualification

## 2. Client problem to approved solution

Discovery → Current-state assessment → Options → Target design → Estimate → Proposal → Agreement

## 3. Approved solution to accepted outcome

Plan → Configure/build → Test → Change management → Acceptance → Documentation → Handoff

## 4. Managed environment to continuous improvement

Observe → Review → Prioritize → Approve → Change → Verify → Report

## 5. Delivery experience to reusable knowledge

Capture → Normalize → Review → Publish → Reuse → Measure → Improve

## 6. Partner need to governed delivery

Identify gap → Select partner → Qualify → Contract → Coordinate → Verify → Review

## 7. Business activity to financial control

Quote → Contract → Deliver → Record time/cost → Invoice → Collect → Analyze margin
