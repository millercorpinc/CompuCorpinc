# Delivery Playbook

## 1. Intake

- Confirm signed scope and payment terms
- Identify sponsor, technical contacts, and decision-makers
- Confirm customer responsibilities
- Establish secure access
- Create project workspace
- Record assumptions, risks, and dependencies

## 2. Plan

- Break scope into workstreams
- Assign owner roles
- Define milestones
- Define test and acceptance
- Identify partner activities
- Establish change and communication cadence

## 3. Design

- Confirm current state
- Document target state
- Review security and data
- Resolve material decisions
- Obtain approval for exceptions

## 4. Implement

- Pilot high-risk changes
- Use named administrative accounts
- Record changes
- Maintain rollback considerations
- Escalate scope changes
- Keep customer informed

## 5. Test

- Test normal and exception paths
- Verify security controls
- Verify monitoring
- Confirm user and administrator experience
- Record defects and remediation

## 6. Accept and hand off

- Obtain customer acceptance
- Deliver architecture and runbooks
- Transfer operational ownership
- Record open risks
- Define support and escalation
- Confirm recurring-service start or project closeout

## 7. Learn

- Compare planned and actual effort
- Review margin and scope changes
- Capture reusable assets
- Update service standards
- Record customer evidence
- Identify recurring and expansion opportunities
