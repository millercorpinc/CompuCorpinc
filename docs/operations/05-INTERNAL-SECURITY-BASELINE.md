# Internal Security Baseline

## Objective

Operate the company to the standard it recommends to customers.

## Identity

- Named accounts
- MFA for all users
- Separate privileged access
- Least privilege
- Documented break-glass access
- Periodic access review

## Endpoints

- Managed company endpoints
- Supported operating systems
- Encryption
- Endpoint protection
- Patch management
- Screen lock
- Controlled local administration
- Remote wipe where appropriate

## Collaboration and data

- Controlled external sharing
- Data classification
- Customer separation
- Retention rules
- Approved storage locations
- No customer secrets in source repositories

## Secrets

- Approved password and secret manager
- No shared credentials in documents or chat
- Rotation and offboarding
- API-key inventory

## Logging and response

- Administrative logging
- Security alerting
- Incident-response procedure
- Evidence preservation
- Customer notification decision process

## Vendors and partners

- Security review proportional to risk
- Contract and data-processing review
- Access expiration
- Minimum necessary customer data

## Development and automation

- Version control
- Peer or senior review for high-risk changes
- Testing
- Secret scanning
- Change records
- Rollback and recovery

## Continuity

- Backup of critical company data
- Recovery procedures
- Alternate communications
- Dependency inventory
- Periodic test
