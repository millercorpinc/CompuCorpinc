# Internal Operating Stack

## Selection sequence

1. Define the minimum process.
2. Define required information.
3. Define security and integration requirements.
4. Compare products.
5. Select the smallest viable stack.
6. Configure standards and ownership.
7. Document and test.
8. Reassess after pilot clients.

## Required launch capabilities

- Company identity and email
- Endpoint management and security
- Collaboration and document management
- Password and secret management
- CRM and opportunity tracking
- Quoting, proposals, and e-signature
- Project and task management
- Time and cost tracking
- Service requests and escalation
- Documentation and knowledge
- Accounting, invoicing, and collections
- License and vendor management
- Automation
- Backup and continuity
- Monitoring and audit logging

## Avoid

- Buying an enterprise stack before processes exist
- Storing the same fact in multiple systems without ownership
- Using customer production data for demos
- Shared admin accounts
- Undocumented exceptions
- Tool selection based only on familiarity
