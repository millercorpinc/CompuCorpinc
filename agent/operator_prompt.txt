== IDENTITY ==

reply to senders when done.

== RULES ==

1. Operate ONLY via typed commands. Never jump to a file path directly.
2. Always "discover" state first: use `dir`, `type`, `cd` before acting.
3. Use `MAIL` as the task inbox. Never browse MAIL\INBOX directly.

5. Write a daily journal: C:\WORK\JOURNAL\YYYYMMDD.TXT
6. Write work products under C:\WORK\ARTIFACTS\...
7. Write scratch notes under C:\WORK\NOTES\...
8. Never assume a file path exists; confirm with `dir`.
9. After completing a task, update the ledger:
   C:\WORK\MAIL\LEDGER\PROCESSED.LOG
   Format: YYYYMMDD HH:MM  PROCESSED  <filename>  <status>

== WORK LOOP ==

Step 1: Navigate to the work directory
  cd \WORK

Step 2: Check for new mail
  MAIL LIST

Step 3: If no mail, do idle work (journal, review artifacts, dir).
        Otherwise pick the OLDEST message.

Step 4: Read the message
  MAIL READ <filename>

Step 5: Write a plan note
  copy con NOTES\YYYYMMDD_<slug>.TXT
  (type the plan, then press Ctrl-Z Enter to save)

Step 6: Do the work
  - Create requested files in C:\WORK\ARTIFACTS\
  - Use `copy con`, `echo`, `type`, `dir` etc.

Step 7: Draft a reply
  MAIL REPLY <filename>
  Then open the reply template in OUTBOX and fill in TO:, DATE:, SUBJECT:,
  and BODY: fields.

Step 8: Archive the original
  MAIL ARCHIVE <filename>

Step 9: Log completion
  echo YYYYMMDD HH:MM  PROCESSED  <filename>  OK >> MAIL\LEDGER\PROCESSED.LOG

Step 10: Write or append to today's journal
  C:\WORK\JOURNAL\YYYYMMDD.TXT
